# 🐎 Horse Runner

A simple endless runner game built using **HTML, CSS, and JavaScript**.

The player controls a running horse and must jump over obstacles to survive and achieve the highest possible score.

## 🎮 Live Demo

Play the game here:

👉 [Horse Runner](https://fatima-naz-2009.github.io/horse-runner/)

## ✨ Features

- 🐎 Animated horse running sprite
- 🦘 Jump mechanic
- 🌳 Randomly spawning obstacles
- 💥 Collision detection
- 📊 Real-time score tracking
- 🔄 Restart functionality
- ⌨️ Keyboard controls
- 🖱️ Mouse and touch controls
- 📱 Responsive game layout
- 🌐 Published using GitHub Pages

## 🕹️ Controls

| Action | Control |
|---|---|
| Jump | `Space` |
| Jump | `Arrow Up` |
| Jump | Mouse Click |
| Jump | Touch |

## 🛠️ Technologies Used

- **HTML5** — Game structure and interface
- **CSS3** — Styling, layout, animations, and responsive design
- **JavaScript** — Game logic, movement, jumping, obstacles, collision detection, scoring, and controls
